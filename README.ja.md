## 🌊 現在つくっているもの

### [SeaFlow](https://github.com/HuDeyi-66/SeaFlow)

**SeaFlow** は、私の長期的な法務 AI・証拠インフラストラクチャのプロジェクトです。

異種の資料を、来歴・引用・証拠の境界を保ったまま、信頼でき追跡可能で機械が扱える証拠へと変換する方法を探っています。

現在の原則：

> **Evidence First · Traceable Sources · Small Core · Extensible Skills**

公開対象の 4 Skill リポジトリは承認済み公開範囲で同期済みです。基盤ランタイムと正式な ChenHai 実装は非公開で、WenHai はローカルのみです。

**開発・受入状況：** 6 Skills は、検証済みの Windows/CPython 環境で、合成証拠を用いた **V3.5 の限定的な内部統合受入**を完了しました。**V3.6 の外部ベンチマークは未実施**です。第三者査読、法的正確性の認証、実コーパスでの精度検証、本番運用の認定を意味しません。

[SeaFlow のアーキテクチャと 6 Skills](https://hudeyi-66.github.io/seaflow-library-project-control/) を見る。

## 🧩 SeaFlow の 6 Skills

6 つの Skill はすべて同列の SeaFlow 独立モジュールで、範囲を限定したローカル実装があります。SeaFlow 固有のモジュールであり、Anthropic Agent Skills との互換性を意味しません。ソース公開状況と内部受入結果を区別しています。

### 📘 [ShanHai（海珊）](https://github.com/HuDeyi-66/Shan_Hai_Code_Skill) — 法律テキスト証拠

**主な機能：** Structure、ResolveRefs、出典に忠実なテキスト分割と引用の再構成。

**証拠上の限界：** 引用位置は登録されたテキスト表現に紐づきます。出典ラベルの一意一致は法的参照先の同一性や法的正しさを証明しません。

**ソース公開状況：** 公開ソースリポジトリ.

### 📊 [LuoHai（海珞）](https://github.com/HuDeyi-66/Luo_Hai_Tables_Skill) — 表形式証拠

**主な機能：** ReconstructVerify、AccountLoss、セルの来歴保持と明示的な情報損失の記録。

**証拠上の限界：** 検証範囲は対応形式と選択された証拠に限られ、ワークブック全体の完全性は保証しません。

**ソース公開状況：** 公開ソースリポジトリ.

### 🗂️ WenHai（海玟） — 文書証拠

**主な機能：** RegisterAsset · PreserveTranscript · SegmentEvidence · ExtractAdvice。

**証拠上の限界：** 宣言済みのテキスト位置と編集由来を保存します。未提供の音声、話者の身元、助言の正確さを認証しません。

**ソース公開状況：** ローカル専用の非公開リポジトリ。公開ソースリンクなし.

### 🔎 ChenHai（海琛） — 証拠十分性とプロセス評価

**主な機能：** Φ 証拠十分性、Ψ 検索・調査プロセス評価。

**証拠上の限界：** 証拠の欠落や出典不明を明示したまま扱い、プロセス評価を法的正しさと混同しません。

**ソース公開状況：** 受入済み実装は非公開。公開 ChenHai 探索リポジトリは別の歴史的プロトタイプ ([公開探索プロトタイプ](https://github.com/HuDeyi-66/Chen_Hai_Explore_Skill)).

### 🕸️ [JueHai（海珏）](https://github.com/HuDeyi-66/Jue_Hai_Graph_Skill) — 証拠・来歴グラフ

**主な機能：** Γ 来歴グラフ、型付きイベント、アサーションと登録内容の検証。

**証拠上の限界：** 計算上の派生関係は、法的引用関係、因果関係、独立した裏付けを自動的に証明しません。

**ソース公開状況：** 公開ソースリポジトリ.

### 🕰️ [XianHai（海现）](https://github.com/HuDeyi-66/Xian_Hai_Time_Skill) — 時間的証拠

**主な機能：** 時間的証拠状態の評価、再確認計画、証拠受入判断。

**証拠上の限界：** 法的効力発生時点が不明なら未確定のまま扱い、公布日や予定日から効力を推定しません。

**ソース公開状況：** 公開ソースリポジトリ.

## 🧭 これらのプロジェクトをどう考えているか

私の仕事の背後には、繰り返し現れる構造があります：

**社会的現実 → 制度と規則 → 証拠 → 情報システム → 人工知能**

この連鎖の両方向に関心があります：

- 社会的・制度的な構造をどのように計算的に表現できるか；
- 計算システムが、証拠の生産・組織・利用をどう変えるか。

ここで **法社会学、人工知能、ガバナンス、批判社会学、異文化研究** の関心が交差します。

## 📖 研究 × エンジニアリング

研究とエンジニアリングは、同じ過程のつながった部分だと考えています：

> **観察 → 理解 → 形式化 → 構築 → 再検討**

研究は、注目すべき構造を見つける助けになります。

エンジニアリングは、その構造を明示的にすることを強います。

システムが一度構築されると、その限界がしばしば新しい研究課題を明らかにします。

ここにあるリポジトリのいくつかは安定したツールです。
いくつかは研究プロトタイプです。
いくつかは実験です。

それらは一緒になって、アイデアが徐々にシステムになっていく過程を記録しています。
